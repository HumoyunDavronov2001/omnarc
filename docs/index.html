1 / 4

Seven devices, one model.

Each arc is one device’s share of the model’s 80 layers, sized by its measured memory bandwidth.

2 / 4

Inside an arc, a window of layers.

The token’s hidden state climbs through every layer the device holds. Weights never move; only the state does.

3 / 4

Then 16 KB hops to the next device.

For a 70B model, that is all that crosses the network per token, encrypted over QUIC.

4 / 5

From one home to the world.

Idle devices behind any NAT can join one ring. That is the goal of stage B6, not a shipped feature.

5 / 5

Proof, not opinion.

Four arcs answer in parallel; their hidden states vote, and every public-network answer carries a TOPLOC proof that your ring produced it. Disagreement is a feature: you see the split instead of a confident mistake.

Memory bandwidth and free memory for each.

Stage time for device i holding ℓi layers of size m, with bandwidth βi, hidden state h, link B and round trip r:

τi = ℓi·m / βi + h / B + r

The planner minimises the slowest stage, subject to memory:

min maxi τi   s.t.   Σℓi = L,   ℓi·m ≤ Mi

which water-fills to

ℓi = min( Mi/m,  λ·βi/m ),   λ chosen so Σℓi = L

03The math

      
Three formulas behind the ring.

      
Each one decides a design choice in Omnarc. Move the sliders and watch the trade-off.

    

    

      

        

          
Speculative decoding

          
A small draft model guesses k tokens; the ring checks them in one pass. With acceptance rate α, tokens gained per pass:

          
E[n] = 1 − αk+11 − α,   speed-up = E[n]1 + k·c

          
        

        

          
          
          

        

      

      

        

          
Replicas and uptime

          
Each of W layer windows lives on r devices that are each online with probability p. The ring answers when every window has a copy:

          
Pring = ( 1 − (1 − p)r )W

          
        

        

          
          
          

        

      

      

        

          
Accuracy mode

          
Several devices answer the same question and vote. If each is right with probability q, the majority of n is right with:

          
Pmaj = Σj>n/2 C(n,j) qj(1 − q)n−j

          
        

        

          
          
          

        

      

    

  







  

    

      
04who is it for

      
One mind for what you do.

      
Goals of the roadmap — stages B4, B7 and B8.

    

    

      
B8
Agents on your own model
OpenClaw, OpenCode and other agents run on a frontier-class open model spread across your own computers — no per-token bill, no rate limit. One computer can only stream such a model from disk; a cluster keeps all of it in memory.

      
B7
The family ring
A family or a team shares one assistant that speaks their language; a weak phone joins by voice and computes nothing.

      
B4
Accuracy mode
Several devices answer the same question and check each other; the answer shows how many agreed — a single device’s mistake is caught before you read it.

07questions

      
Questions

    

      
Is Omnarc ready to use?
Not yet; it is pre-alpha. Stage B0 is complete and B1 is in progress: devices can already run one model together as a ring wired by hand. Discovery, QR pairing and planning arrive in B2 and B3.

      
Are the numbers on this page real?
The partition lab uses a bandwidth model of decoding, and the rack view is a simulation. They show how the planner reasons, not measured results. Measured results come from omnarc-gate on your own hardware.

      
Does my data leave my devices?
All traffic is encrypted. On your own network everything stays inside it. On the public network raw text never leaves your device, and every answer carries a TOPLOC proof that your ring produced it. There is no telemetry.

      
Can it really run a 70B model on phones and laptops?
Layers split in proportion to each device’s measured power: a phone holds a few, a PC holds many. The B1 gate is a 70B model across Linux and Windows machines, and omnarc-gate checks every split against the whole model.

      
How do I try it today?
Clone the repo, run cargo test --workspace, then cargo run -p omnarc-node -- info. With the engine built, omnarc-node ring joins two nodes into a ring. The README has the full walkthrough.

      
Is it free?
Yes. Apache 2.0, no account, no telemetry. Credits for the public network arrive only in stage B6.
