# Why the 70B splits failed here: the machine, not the engine.
# The model is 39.6 GB and this laptop has 5.1 GB of memory. gate.sh runs every shard of a split in one
# process, so a split needs the whole model resident at once; the whole-model pass succeeded because it
# streams one window sequentially. Fewer chunks does not help — the reference logits are only ~262 MB per
# chunk, it is the weights that do not fit. The three splits were killed by the kernel, and the engine
# itself reported no error.
# A 70B gate therefore needs either a machine with ~48 GB of memory or the distributed ring of BE-04;
# the hardware at hand (5.1 GB laptop + 11.8 GB Windows PC) cannot hold it. See SPEC BE-03 and BE-04.
